# Portfólio (Quarto + GitHub Pages)

1. Abra a pasta no RStudio (File > Open Project) e instale o Quarto.
2. Troque "Seu Nome", e-mails e links em `_quarto.yml`, `index.qmd` e `pt/index.qmd`.
3. Coloque sua foto em `images/foto.jpg` e os PDFs em `files/cv-en.pdf` e `files/cv-pt.pdf`.
4. Edite `publications.csv` (uma linha por artigo; as duas línguas usam o mesmo arquivo).
5. Rode `quarto preview` para ver o site; `quarto render` gera a pasta `docs/`.
6. Suba tudo para o repositório SEU-USERNAME.github.io e, em Settings > Pages, use a branch main e a pasta /docs.
